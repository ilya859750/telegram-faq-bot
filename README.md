# Telegram-бот FAQ + сбор заявок для малого бизнеса

Бот отвечает на частые вопросы (цены, адрес, график, контакты), понимает свободный текст по ключевым словам, собирает заявки (имя → телефон → запрос), сохраняет их в SQLite и мгновенно уведомляет владельца в Telegram.

**Стек:** Python 3.10+, aiogram 3, SQLite.

## Возможности

- Меню с кнопками, контент берётся из `faq.json` (под нового клиента меняется только этот файл)
- Ответы на свободный текст («во сколько открываетесь?») по ключевым словам(еще не готово)
- Форма заявки с проверкой телефона, кнопка «отправить мой номер»
- Уведомление владельцу о каждой новой заявке
- Дублирование заявок в Google Sheets
- `/leads` — последние 10 заявок, `/export` — все заявки в CSV (открывается в Excel)
- `/myid` — узнать свой Telegram ID, `/cancel` — выйти из формы

## Структура

```
bot.py            логика бота
db.py             работа с базой заявок (SQLite)
sheets.py         дублирование заявок в Google Sheets
faq.json          контент бизнеса: приветствие, вопросы-ответы, ключевые слова
requirements.txt  зависимости
.env.example      шаблон настроек (токен и ID владельца)
```
