# Telegram-бот FAQ + сбор заявок для малого бизнеса

Бот отвечает на частые вопросы (цены, адрес, график, контакты), понимает свободный текст по ключевым словам, собирает заявки (имя → телефон → запрос), сохраняет их в SQLite и мгновенно уведомляет владельца в Telegram.

**Стек:** Python 3.10+, aiogram 3, SQLite.

## Возможности

- Меню с кнопками, контент берётся из `faq.json` (под нового клиента меняется только этот файл)
- Ответы на свободный текст («во сколько открываетесь?») по ключевым словам(еще не готово)
- Форма заявки с проверкой телефона, кнопка «отправить мой номер»
- Уведомление владельцу о каждой новой заявке
- Дублирование заявок в Google Sheets
- `/leads` — последние 10 заявок, `/export` — все заявки в CSV (открывается в Excel)
- `/myid` — узнать свой Telegram ID, `/cancel` — выйти из формы

## Структура

```
bot.py            логика бота
db.py             работа с базой заявок (SQLite)
sheets.py         дублирование заявок в Google Sheets
faq.json          контент бизнеса: приветствие, вопросы-ответы, ключевые слова
requirements.txt  зависимости
.env.example      шаблон настроек (токен и ID владельца)
```

## Запуск локально

1. Создайте бота в Telegram: откройте **@BotFather** → `/newbot` → придумайте имя и username → скопируйте токен.
2. Установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN`.
4. Запустите `python bot.py`, откройте своего бота в Telegram и отправьте `/myid`.
5. Впишите полученное число в `ADMIN_IDS` в файле `.env`, остановите бота (Ctrl+C) и запустите снова.
6. Проверьте: нажмите «Оставить заявку», пройдите форму. Заявка должна прийти вам в чат, а `/leads` и `/export` должны работать.

## Настройка под клиента

Откройте `faq.json` и замените название, приветствие, вопросы-ответы. В `keywords` — слова (в нижнем регистре, лучше основы слов: «цен», «работа»), по которым бот узнаёт вопрос в свободном тексте. В ответах можно использовать HTML: `<b>жирный</b>`, `<i>курсив</i>`.

## Размещение 24/7 (чтобы бот работал, когда компьютер выключен)

Бот работает, пока запущен `bot.py`. Варианты:

- **VPS** (самый универсальный, от ~300 ₽/мес): загрузите проект, настройте `systemd`-сервис с `ExecStart=/путь/venv/bin/python /путь/bot.py` и `Restart=always`.
- **Railway / Render / Fly.io**: подключаете GitHub-репозиторий, задаёте переменные `BOT_TOKEN` и `ADMIN_IDS`, команда запуска `python bot.py`. Учтите: на бесплатных тарифах файл `leads.db` может стираться при перезапуске, нужен постоянный диск (volume).

## Подключение Google Sheets (необязательно)

Каждая заявка дублируется строкой в таблицу Google. Если настройки не заданы, бот просто пропускает этот шаг.

1. В Google Cloud Console создайте проект и включите **Google Sheets API**.
2. Создайте **сервисный аккаунт** (робот-пользователь Google), выпустите для него ключ в формате JSON и сохраните как `credentials.json` в папке бота.
3. Создайте таблицу Google и дайте доступ «Редактор» на e-mail сервисного аккаунта (поле `client_email` в JSON).
4. Впишите ID таблицы (часть адреса между `/d/` и `/edit`) в `.env` → `GOOGLE_SHEET_ID`.

Файл `credentials.json` — это секретный ключ, он в `.gitignore` и не должен попадать в GitHub.
